🚀 Langkah Cepat Menggunakan Tester

  1. Isi Email & Password: Masukkan kredensial akun apa saja pada form "Form Login Akun (Dinamis)" di kolom kiri. Anda juga dapat mengklik tombol chip preset (Crew, SL, DM, Superadmin) untuk mengisi form secara otomatis.
  2. Klik "Masuk & Sambungkan Socket": Sistem akan melakukan request HTTP POST /api/auth/login, mengambil JWT Token, mengisi panel token, dan secara otomatis melakukan *handshake* Socket.IO.
  3. Periksa Status & Rooms: Jika badge di atas berubah menjadi Connected, cek panel "Identitas Akun Terhubung" untuk memastikan room user:<id> dan role:<role> sudah terdaftar.
  4. Uji Latensi: Klik tombol [⚡ Test Ping]. Server akan merespon dengan latensi round-trip (misal 3ms).
  5. Pantau Live Stream: Lakukan aksi di aplikasi (misal SL memberi nilai di Postman / Web, atau kru login pertama kali). Kotak "Live Event Stream" di kanan akan langsung menampilkan data event secara *real-time*!

💡 Tips Pengujian Multi-User:

Anda dapat membuka 2 tab browser secara berdampingan:
• Tab 1: Login sebagai Store Leader atau District Manager.
• Tab 2: Login sebagai Crew.
Saat Store Leader atau DM melakukan penilaian, Anda bisa melihat event crew:stars_earned atau evaluation:buddy_completed langsung diterima oleh Tab Crew secara instan!

Contoh Integrasi Frontend (Vue 3 / Nuxt 3)

Gunakan package socket.io-client dan kirim token pada handshake.

// composables/useSocket.ts
import { ref } from 'vue';
import { io, Socket } from 'socket.io-client';

let socket: Socket | null = null;

export const useGamificationSocket = () => {
  const isConnected = ref(false);

  const connect = (jwtToken: string) => {
    if (socket?.connected) return;

    socket = io(import.meta.env.VITE_WS_URL || 'http://localhost:3000', {
      auth: { token: jwtToken },
      transports: ['websocket', 'polling']
    });

    socket.on('connect', () => {
      isConnected.value = true;
      console.log('⚡ Connected to WebSocket:', socket?.id);
    });

    socket.on('disconnect', () => {
      isConnected.value = false;
    });

    // 1. Tangkap Reward Early Bird
    socket.on('crew:early_bird_reward', (res) => {
      console.log('🎉 Early Bird Diterima:', res.data);
      // Panggil modal selebrasi bintang di UI
    });

    // 2. Tangkap Tambahan Bintang
    socket.on('crew:stars_earned', (res) => {
      console.log('⭐ Bintang Bertambah:', res.data);
      // Animasi saldo bintang bertambah
    });
  };

  return { connect, isConnected };
};
