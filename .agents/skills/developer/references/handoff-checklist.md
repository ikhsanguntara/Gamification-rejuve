# Checklist Handoff ke Unit Tester

Sebelum menyerahkan task yang sudah diimplementasikan untuk ditest:

- [ ] Task apa yang diselesaikan (rujuk ke ID user story/task kalau ada)
- [ ] File/fungsi mana saja yang berubah
- [ ] Acceptance criteria yang harus dipenuhi
- [ ] Edge case yang menurut developer penting untuk dicek
  (contoh: input kosong, angka negatif, request tanpa autentikasi)
- [ ] Dependency/setup yang dibutuhkan supaya kode bisa dites
  (env variable, database seed, dll)
- [ ] Known limitation (kalau ada bagian yang sengaja belum ditangani)
